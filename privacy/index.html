Privacy policy

Last updated November 8, 2026.

Hermes is a personal app used only by its owner, Gavin Zaentz. No one else can use it.

With the owner's permission, Hermes reads his own Google Calendar events (read-only) to tell him about his day. It cannot create, change or delete events.

Calendar data is used only for that purpose. It stays on the owner's private server and is never sold, shared or used for advertising. Hermes's use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

Access can be removed at any time at myaccount.google.com/permissions.
